# 곽동규 작업용 F429 제어 코드 재작성 기록

> 날짜: 2026-10-28 · 기준: 김채희 보드 F429 전환 및 Pi 실물 연결 작업 MD, 00_master_design.md v0.3.1
> 이 기록은 코드 작성·컴파일·소프트웨어 테스트 결과다. 팀원이 수행한 실제 보드 시험과 이번 작성 환경에서 수행한 검사를 구분한다.

## 1. 한 일

- F767용 제어 패키지를 NUCLEO-F429ZI와 CubeF4 1.28.3용으로 다시 작성했다.
- 팀 인증 코드와 공식 통신 형식을 유지하며 HB·서보·모터 제어를 하나의 루프에 연결했다.
- 끝점 센서 없는 기본 동작, 독립 서보 시험, 적용 도구와 호스트·ARM 빌드 검증을 제공했다.

## 2. 반영한 기준

| 항목 | 반영 |
|---|---|
| 실제 보드 | F429ZI. F767용 HAL·CPU·startup·링커 사용을 제거 |
| Pi | Pi 5, ST-LINK USART3, 115200 8N1 |
| 인증·메시지 | 기존 sharekey.c/sk_crypto.c와 헤더 바이트 유지. RID, KEY/REQ/RESP/SYNC, 사유 코드 유지 |
| 기본 정책 | C, N은 인증된 키 LIMIT 사용. A 비교 빌드 지원 |
| 서보·모터 핀 | PD14 TIM4_CH3, PE9/11/13/14 TIM1_CH1~4 유지 |
| 클록 | 시스템 클록은 기존 F429 프로젝트가 소유. 타이머 분주는 실제 APB/TIMPRE로 계산 |
| 끝점 센서 | 기본 off. 시간 기반 위치 추정과 센서 측정 상태를 구분 |
| 통신 보호 | 실제 RID\|HB만 생존 시각 갱신. 2초 미수신 오류 유지 |
| 부팅 | 서보·모터 출력 0, 자동 잠금·자동 시동 없음 |

## 4. 기존 코드 및 전체 설계와의 차이

- 이전 v1의 HSI16 고정 분주와 F7 I²C·watchdog 필드를 F4에 맞췄다. F429 프로젝트의 PLL·RNG 설정을 덮어쓰지 않는다.
- 원래 port의 LED 1초 HAL_Delay를 시간 비교 표시로 바꿔 제어 루프를 막지 않도록 했다.
- 공식 HB를 제어 계층으로 연결했다. HB만으로 arming하거나 오류를 해제하지 않는다.
- 끝점 off 모드의 이동 시간 500ms, 모터 시동 목표 30%는 이번 패키지의 임시 기본값이다. 팀 확정 성능값이나 실측값으로 쓰지 않는다.
- 기본 모터·RTC·OLED·watchdog·반납입력은 off로 두었다. 서보부터 단계별로 시험하기 위한 설정이며 기능 코드는 선택 빌드에 포함된다.
- 공식 네트워크 잠금 명령을 새로 만들지 않았다. 잠금은 로컬 API 또는 명시적인 시험 빌드에서 수행한다. 자동 재잠금 조건은 별도 설계 대상이다.
- PG14 반납 버튼 입력은 선택적으로 감지하지만, 반납할 KID를 임의 선택하지 않는다. 기본 콜백은 눌림 로그만 남긴다. 앱의 인증된 반납 명령은 기존 정책대로 동작한다.
- 기존 원본 인증 파일의 FRAM TODO 주석은 보존되어 있지만 실제 저장 구현은 없다. 최신 전체 설계의 저장 매체는 STM32 내부 Flash다. 이 배포본이 재부팅 후 횟수를 보존한다고 표현하지 않는다.
- `RES|A|00`은 정책 허용 의미를 유지한다. 별도 ACT 로그와 실제 센서·기구 관찰로 물리 동작을 구분한다. 실행 실패 시 횟수는 환불하지 않는다.

## 5. 시험 결과

최종 수치와 빌드 소스 해시는 [VALIDATION_KO.md](VALIDATION_KO.md), `HOST_TEST_RESULTS.json`, `build_support/ARM_BUILD_RESULTS.json`에 기록했다.

- 호스트: 끝점 off/on, 클록 계산, 줄 파서, 인증 정답표, 실제 앱+인증+제어 통합 시험 통과.
- 정책: A/C, C 한도4, 변조01, 재전송02, 동기화 취소03, 재등록·취소 상태 유지 확인.
- 구동: 실제 HB 필요, 인증 실패 시 구동 없음, 물리 거부 시 횟수 환불 없음, 끝점 없는 완료, 오류 유지 확인.
- 경계: deadline에 늦게 도착한 끝점은 타임아웃, overlength 접미사 실행 방지, 시간 카운터 순환 확인.
- 실제 F429 대상 ARM 컴파일·링크: 기본 C / A / 모든 옵션 / 독립 서보 구성 통과.
- 실물: 이번 작업 환경에서는 보드 다운로드·배선·서보·모터 시험을 수행하지 않았다.

## 6. 남은 것

- 김채희 노트북의 실제 CubeIDE 프로젝트 복사본에 적용한 뒤 Build/Run 및 실물 시험.
- 서보 외부 전원 준비, 1200/1800µs 방향·위치·부하 보정.
- Grove 문 입력의 극성·전압 및 모터 배선·전류 확인.
- 반납 버튼의 KID 선택 규칙, 자동 잠금 흐름의 최종 합의.
- 내부 Flash 저장·복원, RTC 신뢰·기간 정책, 반복 시험과 실제 지연 측정.
