# T08 전력 측정 절차 (멀티미터 + Pi 5 자체 측정)

> 작성: 권기백 · 2026-11-28 · 기준: 00 §1 ③축(갱신 통신량·전력), §10 T08
> 목적: **우리 모듈의 동기화(2초마다)와 인증 계산이 전력을 얼마나 더 쓰는지** 실측한다. 결과가 측정기로 구별되지 않을 만큼 작으면 그것도 결과로 적는다("차이가 분해능 이하").
> 예상 시간: 약 30~40분. 담당: 김채희 또는 곽동규 (멀티미터 보유자).

## 0. 준비물
- 멀티미터 1개 (직류 전류 mA 범위, 프로브를 **mA 단자**에 꽂음)
- NUCLEO-F429ZI(현재 시연용 펌웨어), Pi 5(`pi_relay.py`), 노트북(`server.py`)
- 기록: 보드에 올린 **커밋 번호 7자리**, 펌웨어 방식(A/C/B), OLED 켜짐 여부, 멀티미터 모델·범위

## 1. STM32 전류 (멀티미터, MCU 전류만)
NUCLEO-144 보드에는 **MCU 전류 측정용 IDD 점퍼**가 있다(ST UM1974에서 JP5. 보드 실크 인쇄로 먼저 확인).

**연결 (반드시 USB를 뽑은 상태에서)**
1. USB를 뽑는다.
2. IDD 점퍼(JP5)를 뺀다. 점퍼는 잃어버리지 않게 보관한다.
3. 멀티미터를 **직류 mA(예: 200mA) 범위**로 두고, 두 프로브를 점퍼가 있던 두 핀에 하나씩 댄다(집게 프로브 권장).
4. USB를 꽂아 보드를 켠다. 프로브가 떨어지면 MCU 전원이 끊기니 고정한다.
5. 끝나면 USB를 뽑고 **점퍼를 다시 꽂는다.** (점퍼가 없으면 보드가 동작하지 않는다)

**측정 상태** (상태마다 30초 관찰, 표시값의 대표값·최소·최대를 적고 3회 반복)

| 상태 | 만드는 법 | 무엇을 보나 |
|---|---|---|
| S0 단독 | Pi 연결 없이 보드만 켬 | 기준값 (판단 코드는 돌지만 응답 없음) |
| S1 온라인 동기화 | `server.py` + `pi_relay.py` 실행, OLED `ONLINE` 확인 | 2초마다 동기화의 추가 전류 (S1 − S0) |
| S2 인증 반복 | S1에서 `python3 repeat_t01_t03.py --only T01 --count 30 --delay 1` | 인증값 계산(HMAC) 부하 |
| S3 오프라인 | S1에서 노트북의 `server.py`를 Ctrl+C로 종료, 약 6초 뒤 OLED `OFFLINE` 확인 | 오프라인 판정 중 |

- 서보·모터는 AA 전지 전원이라 이 값에 **들어가지 않는다**(MCU 전류만). 필요하면 별도로 적는다(선택).
- OLED가 보드 3.3V를 쓰더라도 IDD 점퍼는 MCU만 잰다. 표에 "MCU만"이라고 쓴다.

## 2. Pi 5 전력 (Pi 자체 측정, 도구 필요 없음)
Pi 5에서:
```sh
cd sharekey
python3 pi_power_log.py --label idle  --seconds 60     # pi_relay.py 끈 상태
python3 pi_power_log.py --label relay --seconds 60     # pi_relay.py + 서버 연결 상태
```
각 3회. 마지막 줄 `# relay: 평균 … W`만 표에 옮긴다. 로그 파일은 저장소에 올리지 않는다.
- 값은 Pi 5 전원 관리 칩(PMIC)이 잰 레일 합계다. 외부 측정기가 아니므로 "Pi 자체 측정"으로 표기한다.

## 4. 해석 규칙 (측정 전에 정함)
- **동기화 비용 = S1 − S0**, 인증 비용 = S2 − S1 (각각 3회 대표값의 평균). Pi 쪽은 relay − idle.
- 차이가 멀티미터 분해능보다 작거나 3회 사이 흔들림 안이면 **"구별되지 않음(분해능 ○mA)"**으로 쓰고 숫자를 지어내지 않는다.
- 결과는 "실물 3회, 멀티미터(MCU만)" / "실물 3회, Pi 자체 측정"으로 표기한다. 실제 차량 전력이나 배터리 수명으로 바꿔 말하지 않는다(계산하면 "계산값"으로 따로 표기).
- 지금 펌웨어는 절전(sleep) 없이 계속 돌기 때문에 S0과 S1의 차이가 작을 가능성이 크다. 그 자체로 "동기화가 전력을 거의 늘리지 않는다"는 근거가 된다.
