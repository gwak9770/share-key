# 11/28 RTC B·D 통합 실물 시험 (T02 만료, RTC 고장·시계 오류용 1회 키)

> 기준 문서: 00 v0.3.31 + PR #52(§6 14) · 02 로드맵 §6 T02 · 시험·보드 조작: 김채희 · 명령 안내·기록 정리: Claude Code
> 실물 결과는 각 1회 실행이다. RTC 고장 시험 결과는 시험자의 화면 확인 보고다.

## 시험 환경

| 항목 | 내용 |
|---|---|
| 보드 | NUCLEO-F429ZI (11/27 재조립 차체, DS3231·SSD1309 I2C1 PB8/PB9, SG90 PD14) |
| 펌웨어 | `feat/rtc-bd` 커밋 `ea09543` 기준 Core 파일 12개(새 파일 `rtc_time.c/h` 포함)를 CubeIDE 1.19.0 프로젝트 사본에 반입. 로컬 `config.h`: `VC_ENABLE_RTC 1`, `APP_POLICY_MODE 'A'`, `VC_DEMO_MODE_SELECT 1`, `VC_STOP_CUTOFF_S 30u`. CubeIDE 빌드 0 errors. ELF 해시 미보존 |
| 중계 | Raspberry Pi 5 `pi_relay.py --serial /dev/ttyACM0` |
| 서버·스크립트 | 노트북 `sharekey/` (`feat/rtc-bd`) |
| 방식 | **B** (부팅 때 USER 버튼으로 선택) |

## 1. RTC 시각 맞추기

- 시험 빌드(`TEST_BUILD 1`)에서 `TEST RTC`로 확인: `2026-11-28 17:23:23 KST UNIX=1795854203`(KST→UTC 변환값 계산과 일치). 손으로 `RTC SET`을 하려다 입력 형식 오류로 콘솔이 보내지 않은 일이 1회 있었다.
- 노트북 시계의 초 경계에 맞춰 `TEST RTC SET`을 보내는 임시 스크립트로 맞췄다. 확인 3회 모두 보드가 노트북보다 1초 늦게 보였다(보드가 RTC를 1초마다 읽어 두는 값이라 생기는 차이).
- 일반 빌드(`TEST_BUILD 0`)로 다시 올린 뒤 부팅 로그 `RTC 2026-11-28 17:36:07 KST UNIX=1795854967`, Pi 로그 시각 17:36:07과 같음. `MODE=A ENDPOINTS=0 SERVO=1 MOTOR=0 TEST=0`.

## 2. T02 만료 직전·직후 (B 방식)

`python -X utf8 repeat_t01_t03.py --vehicle <Pi>:9100 --sync 2 --only T02E` · 2026-11-28T17:40:21+09:00 ~ 17:41:13 · KID `7E093753`, 만료 17:41:00, 여유 5초

| 시험 | 기대 | 맞음 / 시도 | 잘못 허용 | 판정 |
|---|---|---|---|---|
| T02-exp 만료 직전 (만료 7초 전까지) | A(00) | 30/30 | - | PASS |
| T02-exp 만료 직후 (만료 5초 뒤부터) | D(04) | 30/30 | 0 | PASS |

- 00 §10 T02 목표 "만료 직전·직후 각 30회"를 실물 1회 실행으로 충족. 직전·직후 판단 경계는 RTC 오차(약 1초) 때문에 만료 앞뒤 5초는 시험하지 않았다.

## 3. RTC 고장과 시계 오류용 1회 키 (B 방식)

RTC 모듈의 I2C 선 하나를 뺐다가 다시 꽂아 시험했다. 서버는 `net off`(오프라인).

| 순서 | 결과 (시험자 보고) |
|---|---|
| 선 뺌 | OLED `B RTC NG` 또는 로그 `CLOCK INVALID` (결과대로 나옴) |
| 원래 키 40 문 열기 | 04 거부 |
| `app.py clock-key 40 --new-kid 70` → `register 70` | 발급·등록 |
| 키 70 첫 번째 | 허용 |
| 키 70 두 번째 | 05 거부 |
| 선 다시 꽂음 | OLED 돌아옴 |
| 키 70 문 열기 | 04 거부 (시계 정상이면 1회 키는 쓰지 않음, 설계대로). 선을 빼기 전 첫 시도에서도 04, `남은횟수=1` |
| 원래 키 40 문 열기 | 허용 (시계가 돌아오면 원래 기간 키로 복귀) |

- 각 1회 실행. 회차별 시각은 기록하지 않았다.
