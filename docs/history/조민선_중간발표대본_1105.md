## 1. 한 일 (요약 3줄 이내)
- 11/9 포스터 발표용 대본을 문서 "10조 중간발표 대본 (부스 설명 + 시연)"으로 만들었다: 시작 전 체크, 설명 1분 20초, 시연 7단계, 예상 질문 12개, 문제 대처.
- 설명은 제안발표 이후 한 일 위주로 줄였다(피드백 반영 → 만든 것·결과 → 한계·다음).
- 시연은 현재 웹 화면 버튼 이름(공유 키 만들기, 차에 키 등록, 차량 오프라인 등)과 OLED 표시에 맞췄다.
