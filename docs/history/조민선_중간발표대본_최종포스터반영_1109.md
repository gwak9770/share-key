# 조민선 작업 정리 — 중간발표 대본 최종 포스터 반영 + 발표→시연 순서 (11/9)

> 기준 문서: 00_master_design.md v0.3.11 · 날짜: 2026-11-09 · 근거: 최종 포스터(11/7), 권기백 11/7 ③ 20초 멘트, 조민선 말투 수정본(11/9), 시연 검토 7건(11/9, 김채희 확인 포함)

## 1. 한 일 (요약 3줄 이내)
- 대본 순서를 **발표(①~⑧, 약 2분) → 시연(약 2분 40초) → 마무리 인사**로 바꾸고 조민선 말투로 다듬음.
- 시연 검토 7건 반영: 시연 3은 4번 열림(LEFT 3→2→1→0) + 5번째 DENY 05, 매번 문 여닫기 / 시연 1 온라인 횟수 "잠깐 줄었다 2초 뒤 4로" / 시연 2 취소 뒤 2~3초 대기.
- 표현 수정: ③ "횟수 상한으로 제한", 시연 3 "C 방식은 공유할 때 오프라인 사용 한도를 정해 두기 때문에"(우리 아이디어처럼 안 들리게).

## 2. 결정한 것
| 항목 | 결정 | 근거 |
|---|---|---|
| 순서 | 발표 쭉 → 시연 → "감사합니다" | 조민선 |
| 시연 3 | [열기 → 문 당겨 열기(OP) → 닫기(CL, 자동 잠금)] × 4 → 5번째 DENY 05 | N=4, 포스터 ⑥ "4회 허용, 5·6회 거부 05" |
| 시연 1 멘트 | 온라인에서도 열면 잠깐 하나 줄었다가 2초 뒤 동기화로 4로 돌아옴 | 김채희 확인(LEFT 3→4) |
| 시연 2 | 취소 뒤 2~3초 기다렸다 문 열기 | 동기화 2초 주기 |
| ③ 표현 | "막고" → "제한하고" | 포스터 문구 "제한" |
| C 방식 설명 | 기존 방식·비교 대상으로 말함 | 00 §15.3 |
| 위조·재전송 공격 시연 | 질문 있을 때만 | 시간 |
