# 김채희 중간 공유 — Pi + 실물 보드 전체 경로 연결 성공 (C 방식)

> 2026-10-28 · 기준 문서 00_master_design.md **v0.3.1** · 함께 작업: 곽동규(Pi) · 받는 사람: 권기백, 곽동규, 조민선
> 보드는 **NUCLEO-F429ZI** (김채희_중간_보드모델불일치_1028.md 참고)

## 구성 (00 §3 구조 그대로, 처음으로 전부 실물)
```
[김채희 Windows 172.20.10.12] server.py(9000) + app.py
        │ Wi-Fi (같은 핫스팟)
[Raspberry Pi 5 172.20.10.11] ~/sharekey/pi_relay.py --serial /dev/ttyACM0 --server 172.20.10.12:9000
        │ USB (ST-LINK VCP, 115200)
[NUCLEO-F429ZI] sharekey_f429 펌웨어, sk_init('C')
```
- Pi 포트: `/dev/ttyACM0` = STM32 STLink VCP, SER=066CFF515250898367132854 (어제 업그레이드한 ST-LINK ID와 같음)
- Pi→노트북 서버 TCP 9000 접속 확인 (Windows 방화벽 개인 네트워크 허용)
- IP는 이번 접속 값이며 고정 아님

## 결과 (C 방식 N=4, 1회 시행, 13:49~13:51)
| 요청 | 앱 결과 | Pi 창의 보드 로그 |
|---|---|---|
| 첫 동기화 | — | `server sync ok -> ONLINE`, `SYNC applied ver 0 -> 1` |
| register 7 | (앱 화면 위쪽 잘림) | `KEY ok kid=00000007 limit=4` |
| tamper 7 | (앱 화면 위쪽 잘림) | `DENY ... reason=01` |
| replay 7 | 거부 **nonce 만료·재사용** | `DENY ... reason=02` |
| net off → revoke 7 | 서버 VER 2 | `no server response -> OFFLINE` |
| open 7 ×6 | 1~4회 **허용**(남은 3→2→1→0), 5·6회 거부 **오프라인 횟수 초과** | `DENY ... reason=05` ×2 |
| net on → open 7 | 거부 **취소된 키** | `SYNC applied ver 1 -> 2`, `ONLINE`, `DENY ... reason=03` |

- **취소 후 추가 사용 C 4/6회** — 노트북 직결(COM4) 실물 결과·00 §9 PC 결과와 같음
- 오류·멈춤·잘린 줄 로그 없음
- 앞부분(register·첫 open·tamper)의 **앱 쪽 출력은 캡처에 없음** → Pi 보드 로그로만 확인

## 결과 (A 방식, 1회 시행, 13:55~13:58)
- 김채희 프로젝트의 port_stm32.c **복사본만** `sk_init('A')`로 바꿔 빌드·업로드 (노트북 연결) → 보드를 다시 Pi에 꽂고 같은 순서로 실행. 공유 원본은 안 고침
- 서버 상태 초기화(server_state.json, keys 삭제) 후 시작

| 요청 | 앱 결과 | Pi 창의 보드 로그 |
|---|---|---|
| 첫 동기화 | — | `server sync ok -> ONLINE`, `SYNC applied ver 0 -> 1` |
| register 7 | (캡처 위쪽 잘림) | `KEY ok kid=00000007 limit=4` |
| open 7 | 허용, 남은횟수 **제한없음** (김채희 구두 확인, 캡처 잘림) | — |
| tamper 7 | (캡처 위쪽 잘림) | `DENY ... reason=01` |
| replay 7 | 거부 **nonce 만료·재사용**, 제한없음 | `DENY ... reason=02` |
| net off → revoke 7 | 서버 VER 2 | `no server response -> OFFLINE` |
| open 7 ×6 | **6회 모두 허용**, 제한없음 (초록 LED 6회, 김채희 관찰) | DENY 없음 |
| net on → open 7 | 거부 **취소된 키** | `SYNC applied ver 1 -> 2`, `ONLINE`, `DENY ... reason=03` |

## Pi 경로 실물 결과 요약 (각 1회 시행)
| | A | C (N=4) |
|---|---|---|
| 취소 후 추가 사용 | **6/6** | **4/6** (5·6회 05) |
| 변조 / 재전송 / 동기화 후 | 01 / 02 / 03 | 01 / 02 / 03 |
- 00 §9 PC 결과, 노트북 직결(COM4) 실물 결과와 같음
- 반복 시험이 아니므로 T01~T07 목표 달성으로 쓰지 않음

## 아직 안 한 것
- 보드 펌웨어를 **'C'로 되돌리기** (A 시험 후 정리)
- 반복 시험(T01~T07 목표), 서보·LED 외 구동기, 저장·재부팅
- Pi의 `~/sharekey` 사본과 최신 공유본 동일 여부 (동규 보고서에서도 미확인. 이번 시험은 정상 동작)
