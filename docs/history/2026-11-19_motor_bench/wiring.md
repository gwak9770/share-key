# 2026-11-19 모터 시험 배선

버전 `motor-bench-20261119-v1` · 작업일 2026-11-19 · 기준 00 v0.3.24 §8.
아래는 사용자 실물 배선 보고를 기록한 것이다. AI가 사진·장비로 배선을 직접 확인한 것은 아니다.

## 1. 제어선

| STM32 GPIO | 보드 표기 | 커넥터 | MDD3A 신호 입력 |
|---|---|---|---|
| PE9 | D6 | CN10 4번 | M1A |
| PE11 | D5 | CN10 6번 | M1B |
| PE13 | D3 | CN10 10번 | M2A |
| PE14 | D38 | CN10 28번 | M2B |
| GND | GND | 사용할 GND 핀 | GND |

GPIO는 00·통합 [board.c](../../../firmware/stm32/Core/Src/board.c)·실제 시험 소스·IOC에서 교차 확인했다. D/CN 대응은 [ST UM1974 NUCLEO-F429ZI 핀표](https://www.st.com/content/ccc/resource/technical/document/user_manual/group0/26/49/90/2e/33/0d/4a/da/DM00244518/files/DM00244518.pdf/jcr%3Acontent/translations/en.DM00244518.pdf) 기준이다. **PE14와 서보 PD14는 다른 핀**이다. MDD3A 신호 입력과 모터 출력 나사 단자를 구분한다.

## 2. 전원·풀다운

```text
AA 알카라인 4개 / 기존 4구 홀더
  + ───────────────────────── MDD3A VB+
  − ───────────────────────── MDD3A VB−

MDD3A 신호 GND ─────────────── NUCLEO GND
NUCLEO 별도 GND ────────────── 소형 빵판 공통 GND 묶음

STM32 PE9  ──┬─────────────── M1A
             └── 10kΩ ────── 공통 GND
STM32 PE11 ──┬─────────────── M1B
             └── 10kΩ ────── 공통 GND
STM32 PE13 ──┬─────────────── M2A
             └── 10kΩ ────── 공통 GND
STM32 PE14 ──┬─────────────── M2B
             └── 10kΩ ────── 공통 GND
```

- 소형 빵판에 +/− 전원 레일이 없다. 내부적으로 연결된 묶음을 GND용으로 사용했다. 실제 구멍 좌표는 사진·연속성 측정 자료 미제공으로 기록하지 않는다.
- 풀다운 4개는 각각 신호와 GND 사이다. 신호선에 직렬로 넣지 않는다. 이는 MCU 리셋 때 LOW를 유지하려는 배선이며 리셋 파형 실측은 미수행이다.
- 배터리 전원 전류는 빵판을 경유하지 않고 VB 나사 단자에 직접 연결했다.
- MDD3A 5VO는 연결하지 않았다. STM32는 USB 전원 구성이다. 당시 실제 USB 호스트·COM 번호는 미상이다.
- MDD3A GND와 VB−는 보드 내부 공통 접지다. 별도 STM32 GND로 빵판 GND 묶음도 연결했다.

## 3. 모터 출력

- M1 출력 두 단자에 왼쪽 앞·뒤 모터 2개를 병렬 연결.
- M2 출력 두 단자에 오른쪽 앞·뒤 모터 2개를 병렬 연결.
- 각 모터를 개별로 구동해 전진 방향을 확인하고 필요한 모터의 두 출력선을 교환했다(사용자 보고).
- 두 모터 병렬은 각 채널 성공 보고가 있지만 4개 동시 구동은 불안정하다. 모터·홀더 정격, 실제 전류는 미확인이다.

## 4. 현재 연결로 확대하면 안 되는 기능

이번 장치의 서보·문 감지·시험 정지 스위치·OLED 연결과 RTC 핀·전원 회로 확인 및 연결·시험은 미완료다. [통합 배선 안내](../../../firmware/stm32/docs/WIRING_AND_TEST_KO.md)는 향후 참고이며 그 문서의 예전 서보 값 대신 현재 config.h의 2000/1200µs를 기준으로 한다. 이번 모터 시험판에는 통합 안전 입력이나 인증 기능이 없다.

배선 변경 때 USB와 건전지를 모두 분리한다. 켤 때 USB→배터리, 끌 때 배터리→USB 순서를 따른다. 향후 서보 추가 전 실제 부품 정격과 전원 분배를 다시 확인한다.
