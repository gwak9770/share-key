# 임베디드 SW 개발·검증 포트폴리오 활용 초안

버전 `motor-bench-20261119-v1` · 대상 작업 2026-11-19 · 공개 전 사용자 검토용.

## 문제 정의

공유 차량 디지털키의 바퀴 구동부를 준비하면서 NUCLEO-F429ZI와 MDD3A, TT 모터 4개를 연결했다. 인증 펌웨어와 하드웨어 문제를 분리하기 위해 USER 버튼으로 짧게 구동하는 독립 시험 펌웨어를 사용했다. 채널별 2개 병렬 구동은 성공했으나 전체 4개 동시 구동은 불안정했다(사용자 실물 보고, 반복 횟수 미상).

## 수행과 역할

- 사용자 직접 수행: 차체·모터·제어선·공통 접지·풀다운 조립, 모터 방향 수정, 저항·전압 측정, 구동 및 정지 관찰.
- AI 지원: 시험 코드와 절차 준비 지원, 현재 실제 프로젝트 파일 확보·소스 검토·반입, 측정값 정리·계산·기술 기록, ARM 재빌드.
- ST 제공 부분: Cube 생성 초기화·HAL·CMSIS·startup·링커. 사용자 독자 작성 코드로 소개하지 않는다.
- 현재 동작 로직은 원본 프로젝트에서 가져왔다. AI가 새 모터 코드를 작성해 과거 시험 성공으로 기록하지 않았다.

## 가설과 검증 방법

1. 오른쪽 병렬 구동 실패에서 회로 연결 문제를 살피기 위해 병렬 저항과 M2 제어선 저항을 측정하고, M2 전용 시험·단일 모터·병렬 2개·원래 코드 순으로 범위를 나눠 재시험했다. 재시험은 성공했지만 최초 원인은 확정하지 못했다.
2. 4개 동시 구동 불안정에서는 전원 공급 부족 가설을 세우고 MDD3A 입력 전압을 정지·왼쪽·오른쪽·전체 조건별로 비교했다. 구동 중 5.5V에서 4.2V로 낮아지는 것을 관측했다.
3. 실제 소스·IOC·링커·IDE 설정을 원본 해시와 함께 보존하고, 원본과 분리된 위치에서 ARM 재빌드해 코드 보존과 빌드 가능성을 확인했다. 이 검사는 보드 동작 재검증을 대신하지 않는다.

## 데이터와 분석

- 저항 실측 6.8Ω, 측정봉 0.60Ω을 바탕으로 모터 저항을 6.2Ω으로 단순 보정 추정.
- 홀더 무부하 5.54V에서 옴의 법칙으로 모터당 약 0.89A, 4개 합계 약 3.57A를 계산. 실제 전류 측정값은 아니다.
- MDD3A 입력의 정지 대비 전체 구동 전압 강하는 1.3V, 약 23.6%로 계산.
- 전원 가설을 뒷받침하지만 배터리·홀더·접점·드라이버·기계적 부하를 구분하는 추가 시험은 남았다. 순간 4V 미만 하락은 확인하지 못했다.

## 활용 가능한 기술 경험

- GPIO와 물리 커넥터·드라이버 신호를 교차 확인하고 공통 GND·외부 풀다운을 적용한 배선 경험.
- 버튼 재누름 조건과 구동 시간 제한이 있는 독립 부품 시험으로 문제 범위를 나눈 경험.
- 실패 결과를 보존하고 가설→측정→재시험→미확정 항목을 연결한 검증 기록.
- 실측·계산·코드 목표·실물 관찰·재빌드 결과를 구분한 근거 관리.
- 기존 인증 코드와 시험판을 분리하고 버전·SHA-256·의존 소스·빌드 설정을 남긴 형상 관리.

## 한계와 다음 검증

4개 동시 구동 안정화, 전류·최소 전압·PWM 파형 계측, 전원 개선 전후 비교와 반복 시험이 필요하다. 실제 모터 정격·홀더 허용 전류·당시 업로드판 해시·사진·영상은 미확인이다. 서보·센서·OLED·RTC 재조립과 디지털키 통합 검증도 남았다. 안전성 인증·차량 수준 검증·성능 목표 달성으로 확대하지 않는다.
