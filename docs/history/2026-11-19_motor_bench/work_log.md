## 1. 근거와 범위

- 실물 결과·측정값은 시험 담당자가 제공한 작업 보고를 옮겼다. 각 시험의 정확한 시행 횟수는 미상이다.
- AI는 외부 프로젝트의 현재 파일을 직접 읽고 반입·정적 검토·ARM 재빌드를 수행했다. 오늘의 실물 시험을 AI가 재현한 것은 아니다.
- 사진·영상·계측기 자동 기록·당시 업로드 로그는 제공되지 않았다. 증빙 이미지를 생성하지 않았다.
- 이 기록은 모터 부품 시험이다. 팀원이 별도 보드에서 확인한 디지털키 실물 결과와 합산하지 않는다.

- 모터 4개 각각의 구동·전진 방향 확인, M1·M2 각 채널, 왼쪽 2개·오른쪽 2개 병렬 구동 성공 보고(횟수 미상).

- 모터 4개 동시 구동은 저속·조기 정지·간헐적 특정 바퀴 미구동. **안정 구동 성공으로 기록하지 않는다.**
- 정지 5.5V → 4개 동시 구동 4.2V 입력 전압 관측. 전원 공급 부족은 유력 가설이며 확정 원인은 아니다.

## 4. 기준 문서와 차이

핀 PE9/PE11/PE13/PE14, 채널당 2개 병렬, AA 4개와 공통 GND는 00 §8과 일치한다. PE14는 서보 PD14와 다르다. 외부 풀다운 10kΩ은 사용자 실물 배선 보고이며 제조사 필수 지정값으로 쓰지 않는다.

| 항목 | 팀 통합 기준 | 확보한 독립 시험판 | 판단 |
|---|---|---|---|
| 개발 도구 | CubeIDE 1.19.0, 2.x 금지 | 설치 제품 정보 2.3.0 확인 | 규칙 차이 보고. 팀 표준 변경 없음 |
| Cube 패키지 | CubeF4 1.28.3 | IOC에 FW_F4 V1.28.3 | 설정 일치. IOC 생성 도구는 CubeMX 6.19.0 |
| 모터 출력 | TIM1 하드웨어 PWM 10kHz, 상한 60% | GPIO 소프트웨어 PWM 목표 약 100Hz·40% | 시험 목적의 차이. 통합 성능으로 주장하지 않음 |
| 구동 조건 | 인증·문·잠금·HB·오류 유지 | USER 버튼·약 500ms 제한 | 인증·안전 입력 검증 대체 불가 |
| ETH·USB_OTG_FS | Disable | IOC·main.c에 활성화·초기화 존재 | 원본 보존. 통합판에 복사하지 않음 |
| FLASH | 저장 영역 제외 1792K | FLASH 링커 2048K | 통합 저장 영역을 보호하지 않는 설정. 디지털키 프로젝트에 적용 금지 |

00·통합 Core·Python 판단 코드·매니페스트는 수정하지 않았다. 요청에 따라 차이만 보고한다. IDE 프로젝트 파일은 사용자 명시 요청에 따라 이 독립 예제에 한해 보존했다. 원본 소스에 날짜 주석을 삽입하면 해시가 달라지므로 버전·날짜는 예제 README와 반입 매니페스트에서 관리한다.
