# 전압 강하 및 모터 구동 트러블슈팅

버전 `motor-bench-20261119-v1` · 작업일 2026-11-19 · 측정·시험 시각 및 반복 횟수 미상.
관찰·측정은 사용자 직접 수행 보고, 계산과 분석은 해당 보고를 기준으로 정리했다.

## 1. 오른쪽 모터 2개 병렬 구동 실패

문제: 오른쪽 모터 2개 병렬 구동이 처음에 실패했다.

수행 순서(사용자 보고):

1. 오른쪽 모터 2개 병렬 저항 3.7Ω 측정.
2. M2A 0.69Ω·M2B 0.68Ω 제어선 저항 측정.
3. M2 전용 시험 코드 작성·업로드.
4. 오른쪽 모터 1개 재시험 성공.
5. 오른쪽 모터 2개 병렬 재시험 성공.
6. 기존 통합 시험 코드 복구 후 채널별 재시험 성공.

분석: 측정봉 자체 저항은 0.60Ω이다. 제어선 측정값은 측정봉 저항과 가까우며 작은 저항 차이를 정확한 배선 저항으로 확정할 수 없다. 저항·연속성 확인만으로 부하 중 전압 강하, 접촉 불량, 순간 단선이 배제되는 것도 아니다. 재시험 성공은 최초 원인이 해소됐다는 증거가 아니다. **정확한 원인은 미확정**이다. M2 전용 과거 소스·업로드 로그는 미확보다.

## 2. 모터 4개 동시 구동 불안정

관찰: 개별 모터·채널별 2개는 정상 구동했으나 4개 동시에는 저속 회전, 평소보다 이른 정지, 특정 바퀴의 간헐적 미구동이 있었다. 실제 지속 시간·속도·부하·반복 횟수는 미상이다. 최대 500ms 코드 종료와 관찰된 조기 정지를 시간 계측으로 구분하지는 못했다.

가설: 동시에 필요한 전류가 커질 때 배터리·홀더·접점·배선의 공급 능력이 부족할 수 있다. 제어 파형, 기계적 부하, 드라이버 상태도 아직 배제하지 않았다.

검증: 멀티미터로 MDD3A VB+와 VB− 사이의 입력 전압을 구동 조건별로 측정했다.

| 조건 | 전압(사용자 측정 보고) |
|---|---:|
| 정지 | 5.5V |
| 왼쪽 모터 2개 | 4.6V |
| 오른쪽 모터 2개 | 4.7V |
| 모터 4개 동시 | 4.2V |

[원시 전압 CSV](voltage.csv), [원시 저항 CSV](resistance.csv). 무부하 홀더 5.54V와 MDD3A 입력 정지 5.5V는 다른 측정이다. 계측기 모델·정확도·표시 갱신 주기·측정 접촉 위치 상세는 미상이다.

분석: 구동 조건에 따라 전압이 낮아졌다는 관찰은 공급 경로 문제 가설을 뒷받침한다. 하지만 멀티미터 표시 4.2V가 순간 최저값이라는 보장은 없고, 순간적으로 4V 미만이었는지 확인하지 못했다. 드라이버 보호 동작·리셋·과전류를 실제 확인한 것도 아니다. **원인 확정 및 개선 후 재시험은 미수행**이다.

## 3. 계산값 — 실제 전류 측정 아님

| 항목 | 계산식 | 계산값 |
|---|---|---:|
| 모터 저항 보정 추정 | 6.8 − 0.60 | 6.2Ω |
| 모터 1개 예상 구속 전류 | 5.54 / 6.2 | 약 0.89A |
| 채널당 2개 | 2 × 5.54 / 6.2 | 약 1.79A |
| 모터 4개 합계 | 4 × 5.54 / 6.2 | 약 3.57A |
| 동시 구동 전압 강하 | 5.5 − 4.2 | 1.3V |
| 정지 대비 감소율 | (5.5 − 4.2) / 5.5 × 100 | 약 23.6% |

구속은 모터 축이 멈춘 상태다. 위 전류는 무부하 홀더 전압과 보정 추정 저항에 옴의 법칙을 적용한 단순 계산이다. 브러시 접촉·축 위치·권선 온도·배터리 전압 강하·배선·드라이버 손실을 반영하지 않는다. PWM 40%에서의 평균·피크 전류 측정값도 아니다. 채널 계산값이 정격 아래라는 이유로 전원 여유나 안정 구동을 보장하지 않는다.

오른쪽 병렬 저항 실측 3.7Ω은 모터 보정값 6.2Ω 두 개의 이론 병렬값 3.1Ω과 별개다. 측정봉·접점·측정 조건이 포함되므로 서로 바꿔 쓰지 않는다.

## 4. 제조사 자료와 해석

[Cytron 공식 제품 사양](https://www.cytron.io/c-stepper-driver/p-3amp-4v-16v-dc-motor-driver-2-channels) 확인: 2026-11-19. 입력 DC 4~16V, 채널당 연속 3A·피크 5A, PWM 입력 최대 20kHz, 3.3V 제어 입력 지원, 5V 출력 최대 200mA다. 제품 페이지가 연결하는 [공식 데이터시트](https://docs.google.com/document/d/1ax3gSo0srTzoSr2bo8ETLym0OqrYjlk_JCZK4kxtfXg/edit)는 브라우저에서 본문을 읽지 못했으므로 피크 허용 시간·정확한 저전압 차단점은 이 기록에서 확정하지 않는다.

4.2V 표시는 사양의 입력 하한 4V에 가깝지만 사양 범위와 실물 안정성 확인은 다르다. 현재 드라이버가 특정 보호 기능으로 정지했다고 단정하지 않는다.

## 5. 검토만 한 개선안

| 후보 | 다음 확인 사항 | 현재 상태 |
|---|---|---|
| 새 알카라인 AA 4개 | 교체 전후 동일 조건 VB 전압·전류 비교 | 미적용 |
| 니켈수소 충전지 | 셀 수·실제 전압·방전 능력·충전 관리·드라이버 하한 확인 | 미적용 |
| 외부 전원공급기 | 모터 정격에 맞는 전압·전류 제한, 공급 배선 확인 | 미적용 |
| 순차 기동 제어 | 기동 겹침을 줄인 효과와 총부하 비교 | 미구현 |
| 6구 홀더와 강압 회로 | 모터·서보 허용 전압, 강압 출력 전류·기동 응답 검토 | 미적용, 현재 설계 변경 아님 |

00은 AA 4구를 사용하며 6개 직렬 9V를 서보·TT 모터에 직접 공급하지 않는다. 6구+강압은 검토 후보일 뿐 이 제한을 바꾸거나 직접 연결을 승인한 내용이 아니다.

다음 검증에서는 전원 한 항목씩 바꾸고 같은 부하·반복 횟수로 비교한다. 모터·홀더 정격, 구동 중 VB 최소 전압·공급 전류·PWM 파형·기계적 걸림을 함께 확인하고 원인을 좁힌다. 아직 이 계획의 결과는 없다.
