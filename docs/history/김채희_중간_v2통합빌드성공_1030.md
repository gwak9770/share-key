## 결과 (서보·전원 연결 없음, 노트북 중계 COM4, 1회 시행)
- 부팅: `# boot F429 vehicle control v2`, `# MODE=C ENDPOINTS=0 SERVO=1 MOTOR=0 TEST=0`, SYNCREQ 2초 주기, OFFLINE
| 요청 | 앱 결과 | 보드 로그 |
|---|---|---|
| register 7 | 등록 성공 | `KEY ok kid=00000007 limit=4` |
| open 7 (온라인) | 허용, 남은 3 | **`AUTH ALLOW CMD=01 LEFT=3 ACT=OK`** → `ACT DONE POSITION=UNLOCKED SOURCE=ESTIMATED` |
| tamper / replay | 거부 01 / 02 | `DENY ... reason=01` / `reason=02` (ACT 없음) |
| net off → revoke 7 → open ×6 | 1~4회 허용(3→2→1→0), 5·6회 **05** | 허용 4회 모두 `ACT=OK`, 거부 2회 `reason=05` (ACT 없음) |
| net on → open 7 | 거부 **03** | `SYNC applied ver 1 -> 2`, `ONLINE`, `reason=03` |
- **취소 후 추가 사용 C 4/6** — v2 적용 전 결과와 같음 → 판단 결과 변화 없음
- `LINK_STALE` 없음 → 노트북 `pi_relay.py`의 HB가 정상 수신됨
- 시험 중 실수: 첫 시도에서 `net off`와 `revoke`가 한 줄로 붙어 실행 안 됨 → 오프라인 부분만 다시 해서 위 결과

## 아직 확인 못 한 것
- **서보 실제 동작** (4구 홀더 없음). `ESTIMATED`는 시간(500ms)으로 추정한 위치일 뿐
- Pi 5 경유 경로로 v2 재확인, A 방식 v2 빌드
