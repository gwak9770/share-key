## 알게 된 것
- OLED `DOOR`는 바뀌는데 로그가 없으면 **스위치·배선은 정상이고 펌웨어 쪽**(올라간 판) 문제
- 중계를 보드보다 늦게 켜면 부팅 때 첫 `CLOSED` 로그는 놓침 → 스위치를 한 번 뗐다 누르면 그때부터 찍힘(기백 안내)
- 노트북 중계에서도 로그 앞에 `[Pi]`가 붙는 건 정상. 9101 확인 주소는 `127.0.0.1`

## 요청
- **권기백:** 6번은 `_v6` 새로 만들어 해결. 기준 코드 승격(00 §14) 판단은 남은 미확인 항목 실물 확인 뒤
- 프로젝트를 여러 번 덮어쓰면 어느 판이 올라갔는지 헷갈림 → **판이 바뀌면 이전 판 복사본 + 새 판 파일 전체 덮어쓰기**로 정리하는 게 안전
- 프로젝트를 복사하면 **.launch가 같이 따라와 옛 .elf를 올릴 수 있음**(README_STM32 ".launch는 복사하지 않는다"). 올린 뒤 Console의 **.elf 이름**을 매번 확인
- **곽동규·권기백:** `sharekey.c/h`에 `sk_get_key_view()`가 추가됨(읽기 전용, 공유 코드 변경) → 공유 `stm32/sharekey.c/h` 반영·승인 필요(00 §9 "같은 파일")
