## 5. 시험 결과
모두 **1회 시행**(다시 잠그기 온라인만 5회). 목표 달성(T 항목)으로 쓰지 않는다.

| 시험 | 방법 | 결과 |
|---|---|---|
| OLED 큰 글자 (1102) | `_v2` 업로드, 노트북 직결 COM4 | 4줄 `C` / `WAIT·ALLOW·DENY` / `LEFT n` / `UNKNOWN·UNLOCK EST·LOCK EST`. **문 상태 표시는 없음** |
| **다시 잠그기 온라인 (1102)** | open → 스위치 누름 | `ACT=OK`·`UNLOCKED` → `DOOR CLOSED -> LOCK ACT=OK`·`LOCKED`. **13:54~13:56 5회 연속 성공**, 서보 왕복(눈으로 확인) |
| 잠긴 뒤 스위치 뗌 | — | `UNKNOWN` (코드대로) |
| 온라인 남은 횟수 | — | 계속 `LEFT 3` (2초마다 동기화로 복구, 정상) |
| 오프라인 C + 다시 잠그기 (1102) | 노트북 직결 | 1회째 잠그는 중에 **`FAULT=DOOR_OPEN`** (0.5초 안에 스위치 떨어짐) → 서보 막힘. 판단은 정상 **C 4/6** |
| 1103 R1 업로드 | `_v3`, `VC_DEMO_MODE_SELECT 0` | Download verified |
| **실물 Pi 경유 연결** | Pi SSH: `python3 pi_relay.py --serial /dev/ttyACM0 --server 172.20.10.12:9000` / 노트북: `server.py`, `web_app.py` | 탭 B `ONLINE` |
| 키 등록 (웹) | 차에 키 등록 | Pi 로그 `KEY ok kid=00000007 limit=4`, 웹 `7번 유효 · 차 등록 1/8` |
| **OLED 멈춤** | 등록·열기 | OLED가 `C / WAIT / LEFT -- / UNKNOWN`에 멈춤. 서보는 움직임. 선 다시 꽂기·RESET으로 안 풀림 |
| OLED 멈춤 풀기 | 배터리 빼기 → OLED VCC 뺐다 꽂기 → RESET → 등록 | **`KEY OK` 표시** |
| **다시 잠그기 (1103 R1, Pi 경유)** | 문 열기 → 스위치 뗐다 누름 | 서보 열림 → 잠금, OLED 바뀜. 여러 번 성공 (횟수 안 셈) |
| **오프라인 C + 다시 잠그기 (1103 R1, Pi 경유)** | 웹: 차량 오프라인 → 키 취소 → 문 열기 ×6(허용 때마다 잠금) → 차량 온라인 → 문 열기 | 허용 4회(LEFT 3·2·1·0), **매번 서보 열림 → 잠금**, 5·6회 **05**, 온라인 후 **03**. **C 4/6, FAULT 없음** |

- OLED 멈춤 원인은 **추정**: I2C가 한 번 끊긴 뒤(서보 잡음·접촉 불량 추정) OLED 칩이 꼬인 채 남음. OLED는 3V3에서 계속 전원을 받아 보드 RESET으로는 안 풀림. 코드상 실패하면 5초마다 다시 연결을 시도하지만 계속 실패함. **재현 시험은 안 함**
- 1103과 1102의 `oled.c` 차이는 화면 문구(KEY OK/KEY NG/KEY n)뿐이고, 화면을 보내는 방식은 같음 → 1103 코드 문제일 가능성은 낮음
- 확인 못 한 것: 다시 잠그기 10회 연속, ④ USER 버튼 A/C 전환, ⑤ 웹 C/A 캡처, ⑥ FAULT → RESET 복구, OLED 멈춤 재현·원인

## 8. 참고 (사용한 자료, AI 대화에서 나온 중요한 내용)
- 00_master_design.md v0.3.9, 권기백 총정리 1103 (김채희 체크리스트 ①~⑥), 01_gwak_relock_20261102.md
- 시연 구성: 노트북 탭 A `python server.py` / 탭 B Pi SSH `pi_relay.py` / 탭 C `python web_app.py` (`--vehicle 172.20.10.11:9100`) → 브라우저. IP는 매번 `ipconfig` / `hostname -I`로 확인
- 규칙: 서버·중계를 다시 켜면 보드 RESET, RESET하면 키 다시 등록. 전원: 켤 때 USB → 배터리, 끌 때 배터리 → USB
- OLED는 **STM32 보드에 연결** (Pi와 연결 없음). Pi는 USB로 중계만 함
- 사유 코드: 01 위조, 02 재전송, 03 취소된 키(온라인 동기화 후), 05 오프라인 남은 횟수 0
- 다시 잠그기 조건: 문 열림 → 닫힘 변화(디바운스), 잠금 해제 상태, 오류 없음. 해제 위치에서 다시 '문 열기'를 누르면 서보는 안 움직임(정상)
- EST = 끝점 센서가 꺼져 있어서 시간(0.5초)으로 추정한 위치
- 비밀번호·Wi-Fi 정보는 기록하지 않음
