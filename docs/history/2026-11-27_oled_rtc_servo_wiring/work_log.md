# 곽동규 작업 정리 — 하드웨어 및 STM32 제어

> 담당 곽동규, 하드웨어 연결 및 STM32 독립 구동 시험

## 1. 한 일

- NUCLEO-F429ZI에서 DS3231과 SSD1309 OLED를 공용 I²C 버스로 연결하고 화면 출력 및 RTC 시간 유지를 시험했다.
- SG90을 독립 전원으로 시험한 뒤 스위치 1개와 구동부 공용 전원을 배선했다. RC카 2층 구조를 유지하며 배선을 정리하고 부품을 고정했다.
- 실제 독립 시험 코드와 설정을 반입하고 명령줄에서 ARM 빌드를 검증했다.

## 4. 전체 설계와 다른 점

- 기준 00 v0.3.26 §8·§9 및 통합 `Core/Inc/config.h`·`Core/Src/board.c`와 대조했다. 공유키 메시지·판단 규칙과 통합 펌웨어는 기존판 그대로다.
- 시험 OLED는 PD15 리셋과 0x3C→0x3D 응답 탐색을 사용한다. 00의 통합 OLED는 RES 미연결, 코드 기본 주소는 0x3C(SSD1306용 드라이버)다. 통합할 때 실제 모듈 주소와 리셋 방식을 확인한다.
- PD14/TIM4 CH3는 양쪽에 쓰인다. 독립판은 CubeMX가 생성한 `MX_TIM4_Init()`으로 설정한 뒤 부팅 중 1500/1000µs를 출력한다. 통합판은 `board.c`가 타이머를 설정하며 인증·제어에 따라 잠금/해제 2000/1200µs를 쓴다. 통합 시 이중 초기화와 부팅 자동 구동이 생기지 않도록 확인한다.
- 독립판 모터는 USER 버튼과 GPIO 소프트웨어 펄스 폭 변조(PWM)로 구동한다. 통합 설계는 TIM1 10kHz 및 인증·문 상태에 따른 제어이며 기본 설정에서 모터와 RTC가 꺼져 있다. 두 예제와 통합판의 플래시 링커 범위도 다르다(독립 2048K, 통합 1792K). 다른 판을 적용하기 전에 플래시 저장 영역과 적용판을 확인한다.
- 독립판 IOC·GPIO 초기화에는 PF12와 PF15 설정이 없다. 차체는 PF12만 배선했다. 00의 PF15 시험 정지 핀과 추가 스위치는 이번 차체에 적용하지 않았다. 통합 전 PF12의 풀업·눌림 극성·접점 튐 방지를 확인한다.

## 5. 하드웨어 연결 및 GPIO 구성

| 부품·기능 | STM32 핀 | 보드 표기·커넥터 | 독립 시험 구성 |
|---|---|---|---|
| MDD3A M1A / M1B | PE9 / PE11 | D6 / D5, CN10 4 / 6 | 빵판 1, 신호 출력 및 10kΩ 풀다운 |
| MDD3A M2A / M2B | PE13 / PE14 | D3 / D38, CN10 10 / 28 | 빵판 1, 신호 출력 및 10kΩ 풀다운 |
| RTC·OLED SCL / SDA | PB8 / PB9 | D15 / D14, CN7 2 / 4 | 빵판 2, I²C1 100kHz·7비트 |
| OLED RES | PD15 | D9, CN7 18 | `OLED_RST`, GPIO 푸시풀, 초기 LOW, 풀업·풀다운 없음, 저속 |
| SG90 신호 | PD14 | D10, CN7 16 | 주황색, TIM4 CH3 |
| 택트 스위치 | PF12 | D8, CN7 20 | 빵판 3에서 GND 연결. GPIO 설정·입력 시험 미수행 |
| 두 번째 택트 스위치 | PF15 | D2, CN10 12 | 미사용 |
| USER 버튼 | PC13 | 보드 B1 | 기존 모터 시험 입력 |
| LD1 / LD2 / LD3 | PB0 / PB7 / PB14 | 보드 LED | 초록 RTC / 파랑 OLED / 빨강 오류 또는 OSF |

D 표기·커넥터는 ST 공식 핀표와 기존 배선 기록을 대조했다. 입력·출력 설정은 반입 소스와 IOC에서 확인했다. [ST UM1974 Rev 11, 표 17](https://www.st.com/resource/en/user_manual/dm00244518-stm32-nucleo-144-boards-mb1137-stmicroelectronics.pdf) · [11/19 모터 배선](../2026-11-19_motor_bench/wiring.md)

**빵판 2 배선** — RTC 직접 연결을 공용 빵판 경유 방식으로 변경했다. 사용한 2.42인치 OLED 기판 표기는 JMD2.42IIC이며 모듈 핀 순서는 RES, SDA, SCL, VCC, GND다.

| 줄 | STM32 | DS3231 | OLED |
|---|---|---|---|
| 1 | 3.3V | + | VCC |
| 2 | GND | − | GND |
| 3 | PB9 | D | SDA |
| 4 | PB8 | C | SCL |

**전원** — 서보 초기 시험에서는 MDD3A 전원을 떼고 eneloop AA 4개를 SG90 빨강(+)/갈색(−)에 연결했다. 최종 배선에서는 정격 1.2V 니켈수소(NiMH) 4개(정격 합계 4.8V)의 +와 SG90 빨강을 MDD3A VB+에, −와 SG90 갈색을 VB−에 연결했다. DC모터 전류는 빵판을 거치지 않는다. STM32는 별도 USB 전원(CN1)을 쓰며 MDD3A·SG90과 GND를 공유한다. 최종 공용 전원은 배선 완료 상태다.

**부팅 중 SG90이 자동으로 움직인다. 문이나 서보 링크를 조립할 때는 서보 전원을 분리한다.** Pi 5는 미연결 상태다.

## 6. 실험 및 시험 결과

다음 실물 결과는 11/27 곽동규의 보고다. 개별 시험 시각은 미상이다.

| 시험 | 결과·횟수 |
|---|---|
| RTC 재배선 뒤 초 증가·발진기 정지 플래그(OSF) | 녹색 LD1만 점등 보고. 정확한 횟수 미상 |
| OLED 주소 응답 | 녹색 LD1·파란색 LD2 점등. RTC/OLED 공용 버스 통신 성공. 실제 OLED 응답 주소 및 시험 횟수 미상 |
| OLED 화면 | SSD1309 초기화 후 128×64 화면에서 4픽셀 간격 세로 줄무늬 출력 성공. 수평 주소 지정과 8페이지 사용. 정확한 횟수 미상. 줄무늬는 중간 시험 단계 |
| OLED 문자 | 5×7 비트맵을 3배 확대해 `KEY OK`/`KEY NG`를 약 2초 간격으로 교대 표시. 실행 순서당 각 3회. 화면 데이터 1024바이트와 제어 바이트 1개. 표시 내용은 시험 문자열 |
| RTC 날짜·시간 표시 | 중간 시험판에서 날짜와 시간, 초 증가와 `RTC OK` 확인. 정확한 횟수 미상. 반입판은 서보 시험 뒤 `RTC_ShowTime()`을 조건부 1회 호출 |
| RTC 단기 전원 차단 | `RTC_SET_TIME=0`에서 USB 차단·재연결 1회. 차단 직전 19:05:25, 재연결 뒤 19:06:06. 스톱워치 41초, RTC 41초, 관측 차이 0초. `RTC OK`, LD1·LD2 점등 |
| SG90 독립 구동 | 서보 전용 AA 전원에서 1500µs 중앙 이동, 1000µs 회전 및 1500µs 복귀 2/2. 육안 약 30°. 비정상 소음·떨림 및 STM32/OLED 재부팅 관찰 없음. 종료 후 RTC 출력 확인 |
| 당시 CubeIDE 빌드 | `RTC_ShowTime()` 호출을 복원한 뒤 사용자 보고 0 Errors, 0 Warnings. 빌드 시각·횟수 미상 |

스톱워치 41초에는 전원 차단부터 재부팅 및 OLED 화면 확인까지가 포함된다. 순수 차단 시간은 미계측이며 계획한 60초 차단 시험은 미수행이다. 관측 차이 0초는 해당 1회 결과다.

코드에서는 DS3231의 초(0x00)·상태(0x0F)를 읽고, OSF를 부팅 시 지우지 않는다. 0x00~0x06 날짜·시간 설정은 이진화 십진수(BCD), 24시간제와 쓰기 실패 시 LD3·중단 처리를 구현했다. 최초 설정 뒤 사용자가 `RTC_SET_TIME`을 0으로 바꾸고 재업로드했다고 보고했다. 반입 코드도 0으로, 부팅 쓰기 블록이 컴파일에서 제외된다. OLED는 RES LOW 20ms, HIGH 후 100ms 대기한다. RTC 출력은 `RTC_BCD()`, `RTC_DrawText()`, `RTC_ShowTime()`에서 날짜·시간과 OSF에 따른 `RTC OK`/`RTC NG`를 그린다.

TIM4 설정은 내부 타이머 클록 84MHz, 분주 레지스터 83, 자동 재장전 값 19999, 상향 계수, 자동 재장전 사전 로드 켬, PWM 모드 1, 초기 펄스 0, 활성 HIGH다. 계산값은 50Hz(20ms 주기)다. 부팅 시 앞선 RTC·OLED 시험 뒤 5초 대기하고 1500µs로 PWM 시작, 1000→1500µs 2회(각 위치 2초), PWM 정지 후 OLED 응답이 있으면 RTC를 한 번 출력한다. 이후 반복부는 PC13 USER 버튼의 DC모터 시험이다. 기존 소프트웨어 PWM 60%와 약 500ms 상한을 유지한다. [예제 소스](../../../firmware/stm32/examples/mdd3a_motor_test_f429/Src/main.c)

## 7. 미완료 작업 및 제한 사항

- 스위치는 배선만 완료했다. PF12 입력·내부 풀업·디바운싱·디지털키 연동은 미수행이다.
- 최종 공용 전원의 개별·동시 구동, 부하 주행, 전압 강하·소비 전류, MDD3A 단자의 두 가닥 수용에 대한 제조사 허용 여부와 문 장착 부하 안정성은 미검증이다.
- 서보의 1000~2000µs 확대 시험은 제안 단계였으며 약 90° 목표와 최종 문 동작은 미검증이다. 문 방식·치수·재료·서보 장착 위치는 미정이다.
- RTC 장기 정밀도, 실제 디지털키 유효기간 적용, 실물 통합 시나리오는 미검증이다. 반입 작업에서 CubeIDE GUI 빌드·팀 표준 1.19.0 호환 빌드·보드 업로드·실물 재시험은 미수행이다.
