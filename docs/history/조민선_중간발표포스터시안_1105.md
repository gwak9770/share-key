# 조민선 작업 정리 — 중간발표 포스터 시안 10종

> 기준 문서: 00_master_design.md v0.3.9 (11/4판)
> 날짜: 2026-11-05 · 환경: Claude 디자인 캔버스
> 중간 공유한 건: 0건

## 1. 한 일 (요약 3줄 이내)
- 11/3~11/4 팀 MD(권기백 총정리, 김채희 2건, 곽동규 공지)와 00 v0.3.9를 바탕으로 중간발표 **포스터 시안 10종**을 만들었다.
- 시안마다 디자인(색·글꼴·제목 모양)과 구성(6·7·8장, 장 순서)이 다르다. 폼보드 60×90cm에 A4 가로 2열×4행 + 위 6cm 제목 띠로 붙인 모습을 축소(1px = 0.5mm)해서 보여 준다.
- 제안발표 피드백 4개를 각 장에 "피드백 ①~④" 표시로 연결했다.

| 항목 | 결정 | 이유 |

| 시안 형식 | 폼보드 전체 미리보기 1장 = 시안 1개 | 디자인과 구성을 한눈에 비교 |
| 6·7장 시안 | 남는 칸은 실물 사진·QR 칸 | 00 §15.1 배치 규칙 |
| 결과 표기 | A 6/6, C 4/6, 01·02·03, 다시 잠그기 온라인 5회. "각 1회 시행, 목표 달성 아님" 명시 | 00 §15.3 |
| 용어 | 차량 오프라인/온라인, 위조된 요청, 가로챈 요청 다시 보내기. B·C는 기존 방식(비교 대상) | 00 §15.3, 11/4 결정 |
