# 김채희 중간 공유 — OLED(2.42" SSD1309) 실물 표시 확인

> 2026-11-02 · 기준 문서 00_master_design.md v0.3.3 · 받는 사람: 곽동규, 권기백, 조민선
> 공유 코드·발표용 프로젝트(`sharekey_f429_v2`)는 안 고침. **복사본 `sharekey_f429_OLED`**에서 시험

## 부품
- OLED 기판 표기: `JMD2.42IIC`, `JMD_M242OLED`, **IC SSD1309, 128×64, I2C** (00 §8 부품 목록에 없는 2.42")
- 핀: GND · VCC · SCL · SDA · RES. 주소 점퍼 표시는 사진상 안 보였고, 코드 주소 0x3C(8비트 0x78)로 바로 동작

## 배선
| OLED | 보드 |
|---|---|
| GND | GND |
| VCC | 3V3 |
| SCL | D15 (PB8) |
| SDA | D14 (PB9) |
| RES | 연결 안 함 (그대로 동작) |

## 펌웨어 (복사본 `sharekey_f429_OLED`)
- CubeMX: I2C1 = PB8 SCL / PB9 SDA (PB6·PB7 안 씀, PB7은 LD2), Advanced Settings에서 `MX_I2C1_Init`·`MX_TIM4_Init` 호출 안 함
- 복사본 `config.h`: `VC_ENABLE_OLED 0 → 1` (그 외 같음: 정책 C, SERVO 1)
- Build → Run As → Download verified

## 결과 (1회)
- 부팅 직후 8줄 표시: `F429 CONTROL / AUTH`, `ARM 0 READY 1`, `DOOR OPEN`(문 스위치 미연결), `POS UNKNOWN SENSOR`, `MOTOR 0 MOVE 0`, `NONE`, `AUTH - WHY -- LEFT -1`, `ACT NONE / RTC INVALID`
- open / tamper 후 7번째 줄(`AUTH … WHY … LEFT …`)이 바뀌는 것 확인 (김채희 관찰)
- 2.42" 화면이라 글자가 발표 거리에서도 읽을 만함 (주관)

## 요청·결정 필요
1. 권기백: 발표 보드에 OLED 버전을 쓸지 결정. 쓰면 공유 v2 `config.h`의 `VC_ENABLE_OLED`를 1로 바꾸는 변경 + CubeMX I2C1(PB8/PB9) 설정 필요. **결정 전까지 보드에는 `sharekey_f429_v2`(OLED 끔)를 다시 올려 둠**
2. 00 §8 부품: OLED를 **2.42" SSD1309 128×64**로 기록할지 (0.96" SSD1306 구매 필요 여부)
3. 곽동규: 큰 글자 화면이 필요하면 요청 예정 (지금은 동작에 문제 없음)
