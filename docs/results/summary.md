# 비교 실험 결과 요약 — v2 (PC 모의)

- 생성: `python3 sharekey/experiments/compare.py --seed 20261116 --out docs/results/`
- 방식: A, B, C(N = 2·4·8·16), D(N = 4) × 상황 1~4, D-현실 20개 후보 × 상황 1·2.
- A·B·C·D는 `sharekey/core.py` 판단 그대로(가짜 시계). D-현실은 core.py에 없는 규칙이라 `compare.py` 안의 **Python 모의**다.
- 실물 결과가 아니다. 모의 규칙은 `sharekey/experiments/compare.py` 머리말.
- 시도별 결과는 `raw.csv`(상황 1·2·4), 상황 3은 `raw_s3.csv`.
- 읽을 때 주의:
  - 조건 표의 시도 수는 최대 20이다. 그래서 A·B의 "최대 20"은 조건의 상한이고, D-현실 20회 상한은 이 조건 표에서 무제한과 구별되지 않는다.
  - 상황 3의 경고에는 재인증 실패뿐 아니라 다시 온라인이 되어 취소가 동기화된 경우도 들어간다. 재인증 끔은 경고가 나도 정차 컷오프가 없어 관찰 구간 내내 시동이 켜져 있다.
  - D-현실은 상황 1·2만 돌렸다. 상황 3·4에서 D-현실은 D와 같은 재인증·플래시 규칙을 쓴다고 보고 따로 돌리지 않았다.
