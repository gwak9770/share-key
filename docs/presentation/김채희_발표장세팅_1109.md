# 발표 장소 세팅 순서 — 실물 Pi 경유

> 2026-11-09 중간발표 부스 · 기준 문서 00_master_design.md **v0.3.11**
> 보드 `sharekey_f429_OLED_v6` (기백 LIVE 1106 판) · 노트북·Pi는 `sharekey_1106c` 판 (Pi에 새 `pi_relay.py` 복사 끝, 11/9)

## 출발 전
- **챙길 것:** 노트북·충전기, Pi 5·USB-C 전원(또는 보조배터리), 보드 USB 케이블, 4구 AA(여분 건전지), 차 모양 모듈(보드·OLED·서보·스위치), 멀티탭
- **끄는 순서:** 배터리 빼기 → 노트북 탭 3개 `Ctrl+C` → Pi 탭 `sudo shutdown -h now` → 초록 불 꺼지면 Pi 전원 뽑기
- 노트북 **절전 모드 끄기**

## 발표 장소에서 켜기
### 1. 배치·전원
- 노트북 → Pi → 차 모양 모듈 순서로 놓기
- 보드 USB(CN1)를 **Pi**에 꽂기, 배터리는 **아직 빼 둠**
- **핫스팟 켜기** → **Pi 전원** 꽂고 1분 기다리기 → 노트북도 **같은 핫스팟**에 연결

### 2. 노트북 탭 3개 (모두 `sharekey_1106c\sharekey` 폴더에서)
| 탭 | 입력 | 확인 |
|---|---|---|
| ① 서버 | `Remove-Item -Recurse -Force server_state.json, keys -ErrorAction SilentlyContinue` → `python server.py` → `ipconfig` | `시작 port=9000`, **노트북 IP** 메모 |
| ② Pi | `ssh group10@group10.local` → `hostname -I` → `cd ~/sharekey` → `python3 pi_relay.py --serial /dev/ttyACM0 --server <노트북IP>:9000` → **보드 RESET** | **Pi IP** 메모, `문 상태 알림 port=9101`, `ONLINE` |
| ③ 웹 | `python web_app.py --vehicle <Pi IP>:9100` → 브라우저 **새 탭** | 머리말 `4조` |

> ⚠ **② `--server` = 노트북 IP (`ipconfig`)** / **③ `--vehicle` = Pi IP (`hostname -I`)**
> 11/5·11/9 두 번 다 ②에 Pi IP를 넣어 `no server response -> OFFLINE`이 났음

### 3. 점검 (3분)
1. **배터리 연결**
2. 스위치 뗐다 누르기 → ② `DOOR STATE OPEN/CLOSED`, 웹 문 그림 움직임, OLED `DOOR OP/CL`
3. 공유 키 만들기 → 차에 키 등록 → OLED `KEY OK`
4. 문 열기 → 스위치 뗐다 **2초 꾹** → 서보 열림·잠김, OLED `LOCK EST`
5. 다 되면 웹 **새 시연**만 눌러 두기

## 시연할 때
- 손님마다 **새 시연 → 다음 키 번호**로 발급·등록 (서버 다시 켜지 않기)
- 잠글 때 **스위치 2초 꾹** (0.5초 안에 떨어지면 FAULT)
- 탭 ①② **끄지 않기**
- `Remove-Item`은 **처음 켤 때·장소 옮겨 다시 켤 때만** (서버 기록 초기화)

## 문제 생기면
| 증상 | 대처 |
|---|---|
| ② `OFFLINE` 계속 | `--server`가 노트북 IP인지 확인 → `Ctrl+C` 후 다시 실행 → RESET |
| `ssh` 안 됨 | 같은 핫스팟인지, Pi 부팅 1분 더 기다리기 |
| OLED 멈춤 | 5~10초 대기 → RESET → OLED 전원 뺐다 꽂기 → 키 재등록 (몇 번째에서 풀렸는지 기록) |
| `FAULT` | RESET → 키 재등록 |
| 서버·중계를 다시 켬 | **RESET → 키 재등록** |
| 웹에 예전 키 현황이 남음 | 서버 `Ctrl+C` → `Remove-Item …` → 서버 → 중계 → RESET → 웹 → 브라우저 새 탭 |
| **Pi가 계속 안 됨** | **노트북 중계로 전환:** 보드 USB를 노트북으로 → ② `python pi_relay.py --serial COM4 --server 127.0.0.1:9000` → RESET → ③ `--vehicle 127.0.0.1:9100` |

## 말할 때 주의 (00 §15.3)
- 실물 결과는 **각 1회 시행**으로 말하기. C는 **비교 대상**(기존 방식), 4회는 **재부팅당 상한**
- 웹 "자동 잠금"은 잠금 **명령 수락 로그** 기준. 잠금 완료를 센서로 잰 것이 아님
- 한계를 먼저 말하기: 키 RAM 저장(재부팅 뒤 재등록하면 횟수 복구), 마스터키 개발용 값, 메시지 암호화 없음
