## 2. Raspberry Pi 5 관련 (받을 예정)
| 항목 | 내용 |
|---|---|
| 전원 | USB-C. 공식 27W(5V 5A) 권장. 휴대폰 USB-C 충전기(5V 3A)도 켜지지만 USB 장치 전류가 제한된다는 경고가 뜸. Nucleo 하나는 전류가 작아 대체로 문제없음 |
| 냉각 | 중계·로그만 하면 없이 시작 가능. 발열·스로틀링이 보이면 방열판이나 공식 액티브 쿨러 추가 |
| OS | Raspberry Pi OS 64비트 (Pi Imager로 microSD에 설치) |
| 저장 | 보유 SanDisk 16GB microSD |
| Nucleo 연결 | Pi 5 USB-A ↔ Nucleo ST-LINK(USB 데이터 케이블) |
